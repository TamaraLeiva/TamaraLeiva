A Full Stack personal finance management application developed as my **final degree project (TFI)**.

The application focuses on helping users manage their personal finances through income and expense tracking, payment management, and AI-assisted functionalities.

**Key technical aspects:**
- Backend development with Java 21 and Spring Boot.
- REST API development and JWT-based authentication.
- Frontend development using React and Vite.
- Relational database modeling and persistence with MySQL.
- Integration of Google Gemini and OCR services through the backend.

**Technologies:**

`Java 21` · `Spring Boot` · `React` · `Vite` · `MySQL` · `JWT` · `Gemini API` · `OCR`
